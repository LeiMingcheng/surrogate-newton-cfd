Surrogate–Newton CFD project page

Reliable and efficient steady CFD from surrogate predictions through Newton–Krylov correction

A solver-coupled framework for fast full-field prediction and residual-controlled correction in steady aerodynamic CFD.

Interactive demo Paper Code Abstract Method Results

Abstract

Neural surrogates can rapidly predict complete flow fields, but finite training data limit their reliability when aerodynamic optimization moves into geometrically out-of-distribution regimes. We combine surrogate prediction with nonlinear correction in the target numerical solver. The surrogate is used as an initializer rather than an independently accepted solution, and Newton–Krylov updates use the target discrete residual to recover a solver-evaluated state.

The framework is studied on optimization-derived transonic airfoils, online aerodynamic design, and three-dimensional flying-wing configurations. The experiments distinguish prediction accuracy from solver consistency and evaluate the trade-off between learned initialization, correction budget, and conventional cold-start CFD.

Method

1

Surrogate prediction

Geometry and flow conditions produce a complete steady-flow estimate.

2

State injection

The estimate initializes the geometry-matched target discretization.

3

NK correction

The solver updates the coupled state using its own discrete residual.

Optimization-derived OOD evaluation

The benchmark contains geometries visited by aerodynamic optimization rather than small perturbations of one canonical airfoil. The analysis reports physical-space field MSE, aerodynamic-load errors, and the solver residual L2 ratio before and after correction.
